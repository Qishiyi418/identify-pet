# 拉拉队员桌宠

基于 Electron 的 Windows 桌面陪伴应用。透明动画、鼠标互动、随机动作、桌面跑动与撑伞升降，配有独立设置面板。

## 安装与启动

需要 Windows 10/11、Node.js 22.12.0 或以上版本及 npm。在项目根目录打开终端：

```powershell
npm ci
npm start
```

首次安装需要联网下载依赖。之后也可以双击根目录的 `启动拉拉队员桌宠.vbs`。运行 `npm start -- --settings` 会同时打开设置。

`npm test` 会检查配置里的每段素材是否存在、是否与记录的 sha256 一致，以及打包配置和设置处理逻辑。

## 打包安装程序

在 Windows 上运行：

```powershell
npm ci
npm run dist
```

生成 `dist\cheerleader-desktop-pet-<版本>-setup.exe`。安装程序装到当前用户目录，不需要管理员权限，可以修改安装位置，并创建桌面和开始菜单快捷方式。`npm run pack` 只生成免安装目录 `dist\win-unpacked`，方便快速试用。

也可以不在本机打包：在 GitHub 仓库的 Actions → Build → Run workflow 手动构建，或推送 `v0.1.0` 这样的版本标签。构建完成后，在该次运行页面的 Artifacts 下载 `installer`。

- 安装版与从项目目录运行的版本共用设置和日志（见下文），同一时间只会运行一个桌宠。
- 卸载时保留设置，但会删除“开机自动启动”登录项；升级安装不受影响。
- 安装程序没有代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”，点击“更多信息 → 仍要运行”即可。公开分发前建议购买代码签名证书，并在 electron-builder 中配置签名。
- 视频、首帧图和原生观察器源码在安装版中放在 `resources\app.asar.unpacked`，其余文件打包进 `app.asar`。新增素材请放在 `assets/animations/` 和 `assets/posters/` 下，`npm test` 会检查是否遗漏。

## 互动与菜单

- 鼠标移到人物上时显示小猫爪指针，透明区域保留鼠标穿透。
- 点击头部播放摸头回应，再次点击从头播放；点击身体播放互动回应。
- 长按约 500 毫秒可提起人物，拖动后松手播放落地动作；移动超过拖动阈值也可直接拖动。暂停动画时仍可拖动位置。
- 待机时悬停约 0.7 秒，会打招呼并显示随本地时间变化的关心气泡，两次问候至少间隔 1 分钟；可在设置中关闭。
- 跑动时碰到人物，会停下并播放摔倒动作。
- 右键人物、右键或单击托盘图标，可播放动作、手动走两步、撑伞上升/下降、暂停、隐藏、打开设置或恢复位置。
- 双击托盘图标可切换桌宠显示状态；隐藏后单击托盘图标即可重新显示，托盘提示会标明“已暂停”或“已隐藏”。

## 桌宠设置

“常用设置”中的大小滑块会实时缩放人物，支持 160–420 的连续调节与恢复默认大小。调整时保留脚底位置，不再通过滚轮缩放。

日常行为可分别设置随机播放、动作频率（活泼 15 秒 / 适中 1 分钟 / 安静 3 分钟）、条件选择、随机移动、只在原位附近活动、悬停打招呼、保持置顶、全屏避让和开机自动启动。

“只在原位附近活动”默认开启：自动走动和撑伞只在你最后一次拖放、恢复位置或调整大小时的位置附近进行，不会慢慢漂到屏幕中间。开机自动启动写入当前用户的 Windows 登录项，关闭开关即删除。安装版的登录项指向安装目录；从项目目录运行时指向项目文件夹，移动文件夹后需要重新打开这个开关。

关闭设置窗口（也可按 Esc）不会退出桌宠，修改会自动保存。

## 随机动作

连续待机达到设置的动作频率（默认 1 分钟）后选择下一项动作，尽量避免连续重复。高抬腿、瞌睡、吃糖和写作业按“起始一次 → 过程循环 → 收尾一次”播放，**每组总计 30 秒**，包含起始与收尾。解码器准备等待不占播放预算。打游戏、高抬腿单段、喝奶茶、吃面、踢足球、左右张望、伸懒腰和看书各播放一次。

“按条件和权重选择动作”有两种状态：

- **开启：** 按素材可用性、移动开关、时段和独立冷却筛选，再按权重选择。每个动作可设置是否参与、0–10 权重、时段和冷却。权重 0 表示不参与随机播放。
- **关闭：** 恢复原来的等概率随机选择，忽略新增的动作开关、权重、时段与冷却规则；仍遵守素材可用性、随机移动开关和防连续重复。

“白天优先 / 夜间优先 / 用餐优先”会在其他时段降低权重，适合当前动作数量较少的情况；“仅白天 / 仅夜间 / 仅用餐时段”才会限制出现时间。时段按系统本地时间计算，夜间支持跨午夜。没有满足条件的动作时继续待机并定期复查，不绕过规则强行播放。

冷却从实际开始播放后计算，加载失败不消耗冷却。手动点播不受随机规则限制。随机移动开关统一控制自动跑动和撑伞，关闭后仍可手动触发。

## 项目结构

```text
assets/animations/   当前使用的透明动画
assets/posters/      动画首帧与静态备用画面
assets/icons/        应用、托盘图标与猫爪指针
config/runtime.json  动作、交互、随机规则和播放参数
config/movement.json 移动边界参数
src/                 Electron 主进程、人物与设置界面、原生观察器
scripts/launch.cjs   启动器
test/                素材、打包配置与设置逻辑的检查（npm test）
packaging/           安装程序图标与卸载脚本
.github/workflows/   自动检查与 Windows 安装包构建
tools/greenscreen/   绿幕抠像、颜色统一与核对工具（Python）
licenses/            组件许可
package.json
package-lock.json
启动拉拉队员桌宠.vbs
```

修改素材时同步更新 `config/runtime.json` 中的视频、首帧、时长与尺寸；人物轮廓变化后还需要更新 `config/movement.json`。

所有动画的发色、服装和肤色已统一校正到角色首帧参考图：首尾帧按部位（头发、帽子、上衣、彩球、短裤、皮肤、眼睛、蝴蝶结）对齐参考色，中间逐帧平滑过渡；同一组动作的起始、循环、收尾共用校正，循环与衔接不跳色。参考图与工具位于 `tools/greenscreen/`，新增素材按其中说明抠像、校色并核对后再加入。

## 设置与日志

设置保存于 `%APPDATA%\CheerleaderDesktopPet\settings.json`，运行日志为同目录的 `runtime.log`。锁屏、休眠或熄屏时暂停播放，恢复后继续运行。

运行 `npm start -- --diagnostics` 可在上述目录生成 `diagnostics.json`，用于查看窗口和动画状态。

Windows 原生观察器首次运行时会编译到用户数据目录，使用系统自带的 .NET Framework C# 编译器；编译不可用时，对应观察功能降级并写入运行日志。
